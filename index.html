CLO4 · IoT Architecture & Protocol Model

Hardware Abstraction & Local Telemetry Simulation

Browser Simulation Notice: This application is a 100% local browser simulation modeling Wi-Fi / MQTT telemetry and ESP32 sensor logic in JavaScript. No live networking hardware, external MQTT broker, paid APIs, or physical sensors are required or connected.
1. Sensing Layer SCT-013 + ZMPT101B

Models an SCT-013 non-invasive split-core AC current transformer sensor and a ZMPT101B isolated AC voltage sensor module calibrated around the 230 V reference.

2. Edge MCU (JS Engine) ESP32 Microcontroller

script.js emulates ESP32 ADC sampling at the configured interval (1s / 2s / 5s), generating bounded appliance load waveforms, summing total watts (W & kW), and computing current (I = P / V).

3. Control & Telemetry Virtual Eco-Relay & MQTT

Evaluates Total > Threshold to switch the Virtual Eco-Relay GPIO actuator and constructs a local Wi-Fi / MQTT JSON payload without live network transmission.
